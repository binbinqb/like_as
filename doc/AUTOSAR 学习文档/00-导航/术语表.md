## 八、常见易混淆对

| 容易混 | 区别 |
|---|---|
| **PDU vs SDU** | 同一段字节，对上层叫 PDU，对下层叫 SDU |
| **DET vs DEM** | DET 是开发期调试（可移除），DEM 是生产期故障管理（必须保留） |
| **MCAL vs ECU Abstraction** | MCAL 屏蔽 MCU 型号，ECU 抽象屏蔽板级布局 |
| **Interface vs Handler** | Handler 管并发（缓冲/排队/仲裁），Interface 管"有几个、什么实现" |
| **Pre-compile vs Post-build** | 前者编译时定死，后者刷写后可改 |
| **CanTp vs J1939Tp** | 前者 ISO 15765-2（诊断），后者 TP.CM/TP.DT（J1939） |
| **ComM vs Nm** | ComM 管 ECU 内部需求，Nm 管 ECU 之间协商 |
| **RTE vs VFB** | VFB 是设计期抽象，RTE 是它的单 ECU 实现 |
| **Warning: MUST vs SHALL** | MUST 是法律强制，SHALL 是规范强制 |
