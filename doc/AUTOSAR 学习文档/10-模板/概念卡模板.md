## 填写要点

| 部分 | 要求 |
|---|---|
| **一句话** | 不超过 50 字，不用术语解释术语 |
| **为什么需要它** | 用"没有它会怎样"对比，比正面描述更有力 |
| **核心机制** | 优先用图/表，避免长段落 |
| **关键约束** | 必须带条目编号（可追溯） |
| **与相邻概念的区别** | 这是最容易混的地方，必须写 |
| **自检** | 2~3 题，答不上来说明没懂 |

> [!warning] 一个判断标准
> 如果"一句话"你写不出来，说明**还没理解**，不要往下填。
> 先去读原文，回来再写。
